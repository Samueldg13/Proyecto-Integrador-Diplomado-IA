# Chatbot Institucional NLP — CCH Plantel Naucalpan

Un chatbot inteligente que responde automáticamente preguntas sobre horarios, trámites y fechas importantes del plantel usando Procesamiento de Lenguaje Natural (NLP).

## ¿Qué hace?

- 📄 **Lee documentos** → Extrae información de PDFs y CSVs
- 🔍 **Entiende preguntas** → Busca respuestas por significado, no por palabras exactas
- 🤖 **Genera respuestas** → Usa inteligencia artificial para escribir respuestas claras
- 📱 **Funciona en WhatsApp** → Los usuarios reciben respuestas en su celular
